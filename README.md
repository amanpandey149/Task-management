# 🚀 Task Management Application

A modern and responsive full-stack Task Management Web Application built with the MERN Stack (MongoDB, Express.js, React.js, Node.js).  
This application helps users efficiently create, manage, organize, and track their daily tasks with an intuitive and user-friendly interface.

---

## ✨ Features

### 🔐 Authentication & Security
- User Registration & Login
- JWT Authentication
- Password Encryption using bcrypt
- Protected Routes

### 📋 Task Management
- Create New Tasks
- Update Existing Tasks
- Delete Tasks
- Mark Tasks as Completed
- Task Priority Levels (Low, Medium, High)
- Due Date Management

### 📊 Dashboard
- Total Tasks Counter
- Completed Tasks Overview
- Pending Tasks Overview
- Task Progress Tracking

### 🎨 UI/UX
- Fully Responsive Design
- Modern & Clean Interface
- Mobile Friendly Layout
- Smooth Animations
- Toast Notifications
- Dark/Light Mode Support

### ⚡ Additional Features
- Real-Time Updates (Optional)
- Search & Filter Tasks
- REST API Integration
- Reusable Components
- Optimized Folder Structure
